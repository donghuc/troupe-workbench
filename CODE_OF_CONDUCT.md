# Code of conduct

Be kind and assume good faith. Critique code and ideas, not people. No harassment, discrimination or personal attacks, in issues, pull requests or anywhere else connected to the project. The maintainer may edit, lock or remove contributions that break this, and block repeat offenders.

This is a condensed form of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
